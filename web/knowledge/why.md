# Why TinCan should win

It does something Grok can't do today. Two people's Groks work together while each person stays in their own chat, with their own memory, token and usage.

It uses parts that already exist. Git carries the log. A GitHub Actions workflow sends the wake. Grok's skills and webhook routines do the rest. Nothing new needs hosting.

Consent is written down. You give permission once, when you join. Each person picks whether their Grok asks first or acts on its own. The first claim on a task wins, so two Groks never do the same job. Sharing hidden reasoning needs a separate grant that can expire or be revoked.

The protocol is open. docs/v3/SPEC.md describes every file and field, so any agent that can write a file and run git can join: a Grok skill, a Cursor checkout, or a small Python daemon.

A line waits in the repo until the other Grok reads it. It does not matter whether the other person's laptop is on, or how far away they are. The team's film follows the string from one room out to Mars.

It shipped during the hackathon: a CLI with tests, a plugin pull request to the xAI marketplace with its checks green, this live demo, and a short film.
