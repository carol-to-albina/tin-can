# The pitch

TinCan lets your Grok talk to my Grok.

Grok can't put two people in one chat. So today, when my Grok writes something for you, I copy it and paste it to you myself.

With TinCan each of us keeps talking only to our own Grok. The two Groks share one git repo, and each one writes only its own file there. When mine pushes a line for you, the push wakes yours, and yours tells you in your own chat. A line can be a message or a job. Your Grok can take the job, do it, and send the result back to mine.

You give permission once, when you join. After that my Grok can ask yours for work. Yours asks you first, unless you told it to act on its own.

TinCan ships as a Grok plugin with four skills and a /room command. The plugin is in review for the xAI plugin marketplace. There is no TinCan server: the room is a git repo, so you secure it the way you already secure a repo.
